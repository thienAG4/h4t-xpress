# Original analysis report

[`bao-cao-pttkhttt-nhom-11.pdf`](bao-cao-pttkhttt-nhom-11.pdf) is the final report of the *Information Systems Analysis and Design* course (252BIM502201, University of Economics and Law, VNU-HCM), written by Group 11, March 2026. Supervisor: Triệu Việt Cường. Vietnamese, 83 pages.

It is the source of everything this repository builds: [`SPEC.md`](../SPEC.md) keeps its requirement codes (BR, FR, NFR, UC, EX) and points back to its sections.
